# Secure University Academic Records System

## 1. Project Overview
This project aims to develop a secure university academic records management system that protects student information, course enrollments, and academic grades.

## 2. Project Objectives
- Protect academic records from unauthorized access.
- Apply Role-Based Access Control (RBAC).
- Prevent SQL Injection attacks.
- Maintain audit logs for sensitive operations.
- Ensure data confidentiality and integrity.

## 3. System Users
The system supports four roles:

- **Student:** View personal information, enrollments, and published grades.
- **Lecturer:** View assigned courses and enrolled students, and manage grades.
- **Registrar:** Manage student, course, section, and enrollment records.
- **Auditor:** View audit logs and security events.

## 4. Technology Stack
- Oracle Database
- Java 21
- Spring Boot
- Spring Security
- React
- Git and GitHub

## 5. Security Requirements
- Secure password storage using BCrypt or Argon2.
- Role-Based Access Control.
- Protection against SQL Injection.
- Secure session management.
- Audit logging.
- Database least privilege.
